This panel contains sections which have options that helping you control your shop related pages, just navigate to **Appearance > Customize > WooCommerce**. 

We will have a separated tutorial bellow. At this writing, we only introduce to you the general purposes of sections in this panel.

<img src="image\customize_woo.png" data-origin="image\customize_woo.png" alt="">

## Store Notice

This is a option to enable/ disable store notice. It is disacble by default.

If enabled, this text will be shown site-wide. You can use it to show events or promotions to visitors!

![](image\store-notice.png)

## Product Catalog
In this section you will see options to set up your shop page.

![](image\shop_shoppage.png)

1. **Shop page display**

    Choose what to display on the main shop page.

    ![](image\shop_shoppagedisplay.png)

2. **Category display**
    
    Choose what to display on product category pages.

    ![](image\shop_shopcatedisplay.png)

3. **Default product sorting**

    How should products be sorted in the catalog by default?

    ![](image\shop_sort.png)

4. **Products per row**

    How many products should be shown per row?

5. **Rows per page**

    How many rows of products should be shown per page?

    ![](image\shop_row.png)

6. **Shop Layout**

    Select default sidebar for shop page.
