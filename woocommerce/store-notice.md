# Store Notice

This is a small notification on the top of a website that displays on every page:

![](00-_images/woo_store_notice.png)

It is supposed to use when you want to **notify visitors** of **promotion campaigns**, **events** or any other notices. It can be written in HTML format so you can add hyperlinks or make text bold/italic.

To enable it, please go to **WooCommerce > Store Notice > Add content > Check the box “Enable store notice” > Save**
