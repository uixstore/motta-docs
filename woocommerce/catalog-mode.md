# Catalog Mode

The Catalog Mode helps you showcase your products to customers without making them available for checkout or order. With this plugin, you can even restrict the catalog mode for specific user roles or only for Guest (Unregistered) users. 


### Enable Catalog Mode

Just go to **WooCommerce > Settings > Products > Catalog Mode** to check Enable Catalog Mode option
