## Breakpoint

This section contains a option to set a breakpoint where the mobile header displays and the desktop header is hidden

Just go to **Appearance > Customize > Mobile > Header Layout > Breakpoint** to set your breakpoint.


## Pre-build Header Layouts

![Customize Mobile - Header](_images/customize-mobile--header.png#alignright)

Motta supports 12 pre-build header layouts. We call them as "Header V1, Header V2,... Header v10, Header v11", Header v12. Just go to **Appearance > Customize > Mobile > Header > Header Layout** select the options below:

- **Present**: Select the **Use pre-build header** option
- **Prebuilt Header**: Select a **prebuilt header layout**


## Build your own

![Customize Mobile - Header](_images/customize-mobile--header-main.png#alignright)

If you don't like one of pre-build header layouts, or sometimes you want to build your own header layout, or just simply add/remove icons on the header. It's the time to try the header builder!

Please follow the steps below to activate the header builder:

- Go to **Customize > Mobile > Header > Header Layout** and select option **Present** as **Build my own**.
- Go to the **Customize > Mobile  > Header Main** and **Customize > Mobile  > Header Bottom** sections to add items to the header
- Click the button **Add Item** to add a new item to a header column.
