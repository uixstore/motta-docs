# Navigation Bar

![](_images/navigation-bar.png)


## Enable Navigation Bar

To enable the **Navigation Bar**, go to **Appearance > Customize > Mobile > Navigation Bar** and select either the Standard or Standard Adaptive option.


## Navigation Bar Standard

![](_images/navigation-bar-standand.png#alignrightfull)

The navigation bar items (home, shop, cart, account, wishlist, compare) are displayed. You can enable, disable, or sort them.

## Navigation Bar Standard Adaptive

The navigation bar items (home, shop, cart, account, wishlist, compare) are displayed. You can enable, disable, or sort them.
But these items will be changed to add to cart button on the product page.
