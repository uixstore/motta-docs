# Create a popup

To create a popup, you can follow the steps below:

- **Step 1** – Navigate to the **Appearance > Theme Popup > Add New** menu in your WordPress admin sidebar.

- **Step 2**  – Give your page a name by entering it in the **Title** field.

- **Step 3** – Add content to your page using the editor field. You can enter text or common HTML markups to add content, or you can click the **Elementor Editor** button to use the Elementor Builder and add elements to the page.

- **Step 4** – Set individual options for the page in the **Display Settings** meta box. Settings options here will affect the current page only. Learn more about [Display Settings](popup/display-settings.md)
