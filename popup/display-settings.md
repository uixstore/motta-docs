# Display Settings

![Page display settings](_images/page--settings.png#alignright)

Motta also supports customizing these things for each popup.

When you edit a popup with Elementor, and click the settings icon in the lower left corner of the Elementor Widget Panel, you will see options to control the following: enable, triggers, targerting...

These options are located in a box in the Elementor Widget Panel.

In this box, you will see following sections.


### Popup Settings

![Page display settings](_images/popup-settings.png#alignright)

In this section, you can change the settings of the popup

- **Enable Popup** - To enable/disable this popup
- **Hide Overlay** - To enable/disable the overlay of this popup
- **Hide Overlay on Mobile** - To enable/disable the overlay of the popup on Mobile
- **Position** - To select position of this popup such as center, left bottom, right bottom, left top.
- **Frequency** - To do not show the popup to the same visitor again until this much days has passed.
- **Visible** - To show the popup after the page loads or wait for a certain number of seconds before displaying it.
- **Seconds** - To enter the time before the popup is displayed, after the page loaded
- **Include Pages** - To select the pages you want to show this popup
- **Exclude Pages** - To select the pages you don't want to show this popup
