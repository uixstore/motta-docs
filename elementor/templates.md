# Elementor Templates

Like other popular page builder plugin, Elementor provide the Tempalte Libary and give you the ability to create pages with the same general design, or create reuseable design. If you are not family with this template library, you can check this documentation for more information of how using it.

[Elementor Template Library Documentation](https://elementor.com/help/template-library/)

Besides Elementor templates/blocks, the Motta theme has it own predefined templates based on demo pages of the theme. You can download the theme's templates [here](https://github.com/uixthemeswp/motta/raw/main/impoter/templates.zip).

At this time, the theme provides predefine templates that you will get after import the Elementor demo data, or you can import them manually from the exported file we included in the theme package.
