# Help Center

![Customize Blog](_images/customize-blog.png#alignright)

A help center page is a section of a website where customers can find answers to their questions about a product or service. It typically includes a knowledge base, FAQs, and contact information for customer support.

This section contains options for controling the display of help center and article pages. 

## Help Center Page

If you want to have Help Center page, you must create it manually. But if you imported our demo content before, you can use the page we created for you.


To create Help Center page, please go **Pages > Add New** to create a new page.

![Help Center Page](_images/help-center-page.png#alignright)

To tell the theme what page to use for Help Center, go to **Appearance > Help Center > Help Center Page**.


## Prebuilt Header

![Page Customize for Header](_images/customize-help-center_header.png#alignright)

- **Header Layout** - Select a different header layout for the help center and article pages.
- **Hide Topbar** - Enable this option to hide the Topbar of the  help center and article pages.
- **Primary Menu** - Select a primary menu of the  help center and article pages. 
- **Header Transparent** - Enable this option to show the Header Transparent of the  help center and article pages
- **Logo Type** - Select a logo type of the  help center and article pages. 
- **Logo Image** - Select a logo type as image of the  help center and article pages. 
- **Logo Text** - Select a logo type as text of the  help center and article pages. 
- **Logo SVG** - Select a logo type as SVG of the  help center and article pages. 


## Prebuilt Footer

![Page Customize for Footer](_images/customize-help-center_footer.png#alignright)
- **Prebuilt Footer** - Select a footer layout for the  help center and article pages on Desktop. The footer layout will be created by Elementor in Templates > Footer Builder.
- **Prebuilt Mobile Footer** - Select a footer layout for the  help center and article pages on Mobile. The footer layout will be created by Elementor in Templates > Footer Builder.

## Search Bar

This section only applies to help center categories and article pages. The search bar for the help center page is built with Elementor.

![Customize Blog](_images/help-center--search.png)


![Customize Blog](_images/customize-help-center--search.png#alignright)

In this section, you can see following options:

- **Search Bar for** - select which pages you want to show the search bar.
- **Background Color** - select a background color of the search bar.
- **Text Color** - select a text color of the search bar.
- **Spacing Top** - select a padding bottom of the search bar.

## Single Page

![Blog Archive](_images/customize-help-center--single.png#alignright)

This secton contains options for controling the display of article page. It has following options:

- **Hide Sidebar** - To turn on/off of the article page.
- **Sidebar posts number** - To set the number posts of the sidebar
- **Hide Title** - To turn on/off the title of the article page.
