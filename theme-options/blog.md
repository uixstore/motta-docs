# Blog


![Customize Blog](_images/customize-blog.png#alignright)

This section contains options for controling the display of blog and single post pages. 

## Prebuilt Header

![Page Customize for Header](_images/customize-blog_header.png#alignright)

- **Header Layout** - Select a different header layout for the  blog and single post pages.
- **Hide Topbar** - Enable this option to hide the Topbar of the  blog and single post pages
- **Hide Campain Bar** - Enable this option to hide the Campain Bar of the  blog and single post pages
- **Primary Menu** - Select a primary menu of the  blog and single post pages. 
- **Logo Type** - Select a logo type of the  blog and single post pages. 
- **Logo Image** - Select a logo type as image of the  blog and single post pages. 
- **Logo Text** - Select a logo type as text of the  blog and single post pages. 
- **Logo SVG** - Select a logo type as SVG of the  blog and single post pages. 
## Prebuilt Footer

![Page Customize for Footer](_images/customize-page_footer.png#alignright)
- **Prebuilt Footer** - Select a footer layout for the  blog and single post pages on Desktop. The footer layout will be created by Elementor in Templates > Footer Builder.
- **Prebuilt Mobile Footer** - Select a footer layout for the  blog and single post pages on Mobile. The footer layout will be created by Elementor in Templates > Footer Builder.

## Blog Header

![Customize Blog](_images/blog-header.png)


![Customize Blog](_images/customize-blog--header.png#alignright)

Blog header is a the top section on the blog page. It contains the blog title, description.
In this section, you can see following options:

- **Enable Blog Header** - turn on/off the blog header.
- **Blog Header Elements** - select show/hide elements to the blog header.


## Blog Archive

![Blog Archive](_images/customize-blog--archive.png#alignright)

This section contains options for controling the blog layout, trending content section, featured content section, blog navigation type, etc. Following is the details:

**Trending Posts** - turn on/off the trending posts section the top of blog page.

- **Trending Tag** - specify the tag you will use on posts to be displayed as **Trending Content**.
- **Trending Layout** - select trending layout of blog page.
- **Excerpt Length** - enter the number of words of the post excerpt.

**Featured Posts** - turn on/off the featured posts section the top of blog page.

- **Featured Tag** - specify the tag you will use on posts to be displayed as Featured Posts.
- **See All Link** - enter link button see all.
- **Columns** - select the number of columns of the post.
- **Total Number** - enter the number of posts to display in this featured posts section.
- **Featured Posts Positionr** - select the position of post to display in this featured posts section.

**Posts Heading** - turn on/off the posts heading section the top of blog page.

- **Posts Heading Type** - select the post heading type. You can choose "Recent Heading" or "Group Tabs" or "Menu Tabs".

**Blog Layout** - select the blog layout.

**Excerpt Lenght** - enter numner of words to cut off from a post to displays as the post excerpt on the blog page.

**Navigation Type** - select the navigation type. You can choose either "Numeric" or "Load more" button.


## Blog Single

![Blog Archive](_images/customize-blog--single.png#alignright)

This secton contains options for controling the display of single blog page. It has following options:

- **Post Layout** - select the layout of single posts.
- **Author Box** - turn on/off the author biography box at the end single post.
- **Post Navigation** - turn on/off the single post navigation. This is the navigation to the next/previous post.
- **Related Posts** - select to display related posts at the end of post or not.
- **Post Sharing** - turn on/off the post sharing option at the bottom of post and select what social chanels do you want to use.
