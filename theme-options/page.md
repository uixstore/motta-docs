# Page

![Page Customize](_images/customize-page.png#alignright)

This section contains options to control the display of the single page. You can learn more about selecting options for every page by visiting [Display Settings](page/display-settings.md)

## Prebuilt Header

This section only works for the single page and the header layout of the current page is the default header page.

![Page Customize for Header](_images/customize-page_header.png#alignright)

- **Header Layout** - Select a different header layout for the single page.
- **Hide Topbar** - Enable this option to hide the Topbar of the single page
- **Hide Campain Bar** - Enable this option to hide the Campain Bar of the single page
- **Primary Menu** - Select a primary menu of the single page. By default, it will use the Default value which is set in the Theme Customizer
- **Header Transparent** - Enable this option to show the Header Transparent of the single page. This option only works with Header V12
- **Header Text Color** - Select a text dark/light for the header of the single page. This option only works with the Header Transparent
- **Logo Type** - Select a logo type of the single page.
- **Logo Image** - Select a logo type as image of the single page.
- **Logo Text** - Select a logo type as text of the single page.
- **Logo SVG** - Select a logo type as SVG of the single page.

## Prebuilt Footer

This section only works for the single page and the footer layout of the current page is the default footer page.

![Page Customize for Footer](_images/customize-page_footer.png#alignright)
- **Prebuilt Footer** - Select a footer layout for the single page on Desktop. The footer layout will be created by Elementor in Templates > Footer Builder.
- **Prebuilt Mobile Footer** - Select a footer layout for the single page on Mobile. The footer layout will be created by Elementor in Templates > Footer Builder.

## Page Header
![Page Customize for Page Header](_images/customize-page_page-header.png#alignright)

This section works for all pages

- **Hide Page Header** - Enable this option to hide the single page Header of the single page
- **Hide Tilte** - Enable this option to hide the single page Title of the single page
- **Hide Breadcrumb** - Enable this option to hide the Breadcrumb of the single page


## 404 Page

![Page 404](_images/customize-page--404.png#alignright)

- **Layout** - select the layout for 404 page.
- **Prebuilt Header Page** - select a prebuilt header for 404 page.
- **Primary Menu** - select a primary menu for 404 page.
- **Prebuilt Footer Page** - select a prebuilt footer for 404 page.
- **Hide Topbar(For Page)** - turn on/off the topbar for the single page 404.
- **Hide Campaign Bar(For Page)** - turn on/off the campaign bar for the single page 404.
