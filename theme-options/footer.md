# Footer


This section contains options for controlling the layout of the site footer for the entire site.


## Select a footer layout

![Customize Footer Layout](_images/customize-footer--layout.png#alignright)

Motta uses Elementor to build the footer. The templates are created in the **Templates > Footer Builder** section. To select your footer, just go to **Appearance > Customize > Footer > Prebuilt Footer**.

## Create a footer layout

![Customize Footer Layout](_images/footer-builder.png#alignright)

- **Step 1** - Go to Templates > Footer Builder > click Add new to create a new footer
- **Step 2** - Enter the title and click Edit with Elementor to build the footer with Elementor

## Edit a footer layout

![Customize Footer Layout](_images/footer-builder_edit.png#alignright)

- **Step 1** - Go to Templates > Footer Builder
- **Step 2** - Hover on a footer item > click Edit with Elementor button
- **Step 3** - Edit the content you want
