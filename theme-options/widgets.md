# Widgets

WordPress Widgets add content and features to your sidebars. In the Motta, you have following sidebars:

- **Blog Sidebar** - it is displayed on the blog, category, tag, post pages.
- **Single Sidebar** - it is displayed on the single post.
- **Catalog Sidebar** - it is displayed on the shop, product category, product tag pages.
- **Catalog Filter Sidebar** - this is a special sidebar. It is displayed on the shop, product category, product tag pages. But it is only show when you select a  **Products Toolbar Layout** which is supported the filtering icon.
- **Single Product Extra Content** - it is allows you add the content below the summary such as the trust badges manually in the product page.


Remeber to select a layout which has a sidebar in the 
Layout section first if you want sidebars to be displayed.
