# Typography

![Cusomize Typography](_images/customize-typography.png#alignright)

All typography options are located within their specific **Appearance > Customize > Typography** panel. You can select font family, font size, line height, color, etc.


## Main

This section contains typography options for the body, links.

- **Body** - it is the option for the whole site, like post content, page content,... It will affect to the whole site except special elements.


## Headings

This section contains typography options for headings, from **Heading 1 to Heading 6**.

## Header Logo text

This section contains typography options for header logo as text.

## Header Primary Menu

This section contains typograhpy options for menu, sub menu of the primary menu

- **Menu** - customize the font of the main menu.
- **Sub Menu** - customize the font of sub menu.

## Header Secondary Menu

This section contains typograhpy options for menu, sub menu of the secondary menu

- **Menu** - customize the font of the main menu.
- **Sub Menu** - customize the font of sub menu.

## Header Category Menu

This section contains typograhpy options for menu, sub menu of the category menu

- **Menu** - customize the font of the main menu.
- **Sub Menu** - customize the font of sub menu.


## Page

This section contains typography options for the page title of pages.

- **Page Title** - customize the font of title on pages.

## Blog

This section contains typography options for the blog page.

- **Blog Header Title** - customize the font of blog header on the blog page.
- **Blog Post Title** - customize the font of post title on blog page.
- **Blog Post Excerpt** - customize the font of post excerpt on blog page.

## Widgets

This section contains typography options for the widget title.

- **Widget Title** - customize the font of blog header on the blog page.

## Product Catalog

This section contains typography options for the product name, description on the product catalog pages, such as shop, product category, product tag.

- **Page Header Title** - customize the font of page header title on product catalog pages.
- **Product Name** - customize the font of product name on product catalog pages.

## Product

This section contains typography options for the product name, description on the single product page.

- **Product Name** - customize the font of product name on the single product page.
