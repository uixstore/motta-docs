# Shop



![Customize Shop](_images/customize-shop.png#alignright)

This panel contains sections which have options that help you control the display shop, product, cart and other related parts. We will have a separated tutorial for controling the WooCommerce plugin and related plugins bellow. This panel contains following sections:

- Page Header
- Shop Header
- Top Categories
- Catalog Toolbar
- Product Catalog
- Product Card
- Product Notifications
- Badges



## Page Header

This section contains options for controling the products toolbar on the shop page. This is toolbar has tools that help visitors to navigate your shop page easier.

- **Page Header Style** - select page header style of the page header on the products catalog pages.



## Shop Header

![Customize Shop - Shop Header](_images/customize-shop--shop-header.png)

This section display shop header content on the shop page.

- **Shop Header** - turn on/off the section on the shop page.
- **Page Template** - select get content from page template of elementor plugin.




## Top Categories

![Customize Shop - Top Categories](_images/customize-shop--top-categories1.png)

![Customize Shop - Top Categories Options](_images/customize-shop--top-categories2.png#alignright)


This section display top categories content on the shop page.

- **Layout** - select layout section on the shop page.
- **Status Product** - select status product in list categories.
- **Limit** - enter 0 to get all categories. Enter a number to get limit number of top categories.
- **Order By** - select to sort categories.




## Catalog Toolbar


Catalog Toolbar is a section on the top of the shop page, bellow the page header. It contails tools that help visitors easily navigate through your shop page like: columns switcher, products quick search, products filter, products tabs, etc. This section contains options that help you control these tools.

- **Products Toolbar** - turn on/off the products toolbar on the shop page.
- **Layout** - select a layout for the products toolbar. Each layout contains different tools.
- **Catalog View** - select elements in catalog toolbar.




## Product Catalog


This section contains options for controling elements on the shop page.

- **Sidebar** - select style content on the shop page. Go to appearance > widgets find to catalog sidebar to edit your sidebar.
- **Navigation Type** - select the navigation type. You can choose either "Numeric" or "Load more" or "Infinite Scroll" button.
- **Catalog Grid Border** - select add border in product loop.




## Product Card

![Customize Shop - Product Card](_images/customize-shop--product-card.png#alignright)

This section contains options for display product loop.

- **Product Layout** - select a layout the product.
- **Product Hover** - select a layout the hover product.
- **Product Title in** - select fix the number of visible lines of the product title.
- **Product Taxonomy** - select to taxonomy product. You can choose either "None" or "Category" or "Brand".
- **Stars Rating** - turn on/off star rating in product.
- **Wishlist** - turn on/off wishlist in product.
- **Compare** - turn on/off campare in product.
- **Add To Cart** - turn on/off add to cart in product.
- **Quick View** - turn on/off quick view in product.
- **Product Attribute** - select show product attribute in the product card.



## Product Notifications


This section contains options for controling shop notifications.

- **Added to Cart Notification** - select display a notification when a product is added to cart.



## Badges


Motta supports 4 types of product badges. You can enable/disable each of them and control how it display in this section.

- **Badge Shape** - select the shape of product badges. Motta supports round and rectangle shapes.
- **Sale Badge** - turn on/off this badge for your products.
- **Sale Badge Type** - select to simply display a "Sale" text or display the sale percentage.
- **New Badge** - turn on/off the badge for new arrival products.
- **New Badge Text** - enter the text of the new badge. It is "New" by default. You can also set how many days a product set as new from the date it is published on your website.
- **Featured Badge** - turn on/off the featured badge for featured products.
- **Featured Badge Text** - enter the text of featured badge. It is "HOT" by default.
- **Sold Out Badge** - turn on/off the sold out badge for out of stock products.
- **Sold Out Badge Text** - enter the sold out badge text. It is "Sold Out" by default.

> [!TIP] Beside setting newness days, you can set a product as a new one in the **Advanced** tab when editing it.
