# Mega Menu Vertical

![Mega Menu Vertical](_images/mega-menu__vertical.png)

We will take a product category as an example. You can do the same thing in other menus.

1. Go to **Appearance > Menus**
2. Choose **Category Menu** and click **Select** button.
3. Go to **Category 1** and choose **Mega Menu** 

![Mega Menu Vertical - Settings](_images/mega-menu__vertical--settings.png)

4. In the **Mega Menu** tab, select **Enable Mega Menu**. <br/>
5. In the **Mode** option, select **Grid**. <br/>
6. Select **Width** as custom and **873px**.

![Mega Menu Vertical - Menu Tab](_images/mega-menu__vertical--menu-tab.png)

7. Click on **Add Column** to display 2 columns. Set the width of the two columns to 50% to display the background image in the empty space.<br/>
8. Click on the **"+"** to add a menu item. <br/>
9. In the **Mega Menu item** tab, select **Heading** to add a heading for the column. <br/>
10. Click **Add to Menu**.

![Mega Menu Vertical - Menu Tab](_images/mega-menu__vertical--add-taxonomy.png)

Taxonomy List settings

- Taxonomy: Get **Product Category** or **Product Brand**
- Parent Category: Get the categories in the parent category.
- Order: Sort the categories by **Ascending** or **Descending**.
- Order By: Sort the categories by **ID, Title, Menu Order, Product Counts**.
- Limit: The number of categories displayed.
- Offset: The number of categories to be offset.
- Hide empty categories: Hide categories without products.
- New Arrivals: Add a link to the latest product of the category.
- Sale: Add a link to the sale products of the category.

![Mega Menu Item - Taxonomy List](_images/mega-menu__item--taxonomy-list.png)

Add similar content from column 1 to column 2.<br/>
Add content similar to other categories.

11. Switch to the Design tab. Add Background and Background Position for Category.

![Mega Menu Vertical - Design Tab](_images/mega-menu__vertical--design-tab.png)

12. Click **Save Changes** button.
