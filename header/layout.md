# Header Layouts

Motta offers two methods to setup your header layout. You can choose either a pre-built header layout with fixed elements or build your own layout. Just navigate to **Appearance > Customize > Header > Header Layout** and select to use a pre-build header layout or build your own.


## Pre-build Header Layouts

![Customize Header Layout](_images/customize-header--layout.png#alignright)

Motta supports 12 pre-build header layouts. We call them as "Header V1, Header V2,... Header v10, Header v11", Header v12. Just go to **Appearance > Customize > Header > Header Layout** select the options below:

- **Present**: Select the **Use pre-build header** option
- **Prebuilt Header**: Select a **prebuilt header layout**

![Header layouts](_images/header--layouts.jpg)

## Build your own

If you don't like one of pre-build header layouts, or sometimes you want to build your own header layout. In the [Header Builder](header/builder.md?id=activate-the-header-builder), you will find more detailed instructions on how to build your header layout.
