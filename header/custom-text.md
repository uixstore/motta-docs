### Custom Text Options

![](_images\header-custom-text-options.png#alignright)

- **Content** - To add the custom content
- **Color** - To change the text color of the custom text
- **Font Size** - To change the text font size of the custom text
- **Font Weight** - To change the text font weight of the custom text
