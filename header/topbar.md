## Topbar Options

![](_images\customize-topbar.png#alignright)

You can go to **Appearance > Customize > Header > Topbar** to control the top bar, such as turning it on or off, selecting the top bar layout, and setting the content for it.

- **Topbar** - To enable/disable the topbar on the top.
- **Left Items** - To add/remove items to/from the left section of the topbar. You can also reorder them.
- **Right Items** - To add/remove items to/from the right section of the topbar. You can also reorder them.
- **Primary Menu** - To select a menu for the Primary Menu element.
- **Secondary Menu** - To select a menu for the Secondary Menu element.
- **Background Color** - To select the background color of the topbar
- **Color** - To select the color of the topbar text.
- **Hover Color** - To select the hover color of the topbar text.


## Topbar Contents

![](_images\customize-topbar_elements.png)

1. **Language Switcher** - Install <a href="https://wpml.org/">WPML</a> plugin to setup your currency switcher
2. **Currency Switcher** - Install <a href="https://wordpress.org/plugins/woocommerce-currency-switcher/">WooCommerce Currency Switcher</a> plugin to setup your currency switcher
3. **Menu** - Go to **Customize > Header > Topbar > Primary/Secondary Menu** and select your menu.
