# Mega Menu Horizontal


## Home Menu

![Mega Menu Horizontal Home](_images/mega-menu__horizontal-home.png)

Here is an example of a Home menu with the **Tabs** mode. You can use a similar approach on other menus. You will need a top-level Home menu and sub-menus for each tab you want to use.

1. Go to **Appearance > Menus**
2. Choose **Primary Menu** and click **Select** button.
3. Go to **Home(level 1)** and choose **Mega Menu** 

![Mega Menu Horizontal Home - Settings](_images/mega-menu__horizontal-home--settings.png)

- In the **Mega Menu** tab, select **Enable Mega Menu**. <br/>
- In the **Mode** option, select **Tabs**. <br/>
- Select **Width** as custom and **857px**.

![Mega Menu Horizontal Home - Menu Tab](_images/mega-menu__horizontal-home--menu-tab.png)

4. Click **Save Changes** button.

You can select **Edit Tab** to add content to each tab.

![Mega Menu Horizontal Home - Menu Tab](_images/mega-menu__horizontal-home--edit-tab.png)

In the Content tab, select **Add Row** to create a row for content. Choose 1 column.

![Mega Menu Horizontal Home - Add Row](_images/mega-menu__horizontal-home--add-row.png)

- You click on the **"+"** and in the **Mega Menu Item** tab, select **Image Box**. <br/>
- Click **Add to Menu**.

![Mega Menu Horizontal Home - Add Image Box](_images/mega-menu__horizontal-home--add-image-box.png)

In the Image Box settings, you need to enter the **Image, Url, Text Alight, etc.**

![Mega Menu Horizontal Home - Image Box Settings](_images/mega-menu__item--image-box.png)

Click **Save Changes** button.




## Shop Menu

![Mega Menu Horizontal Shop](_images/mega-menu__horizontal-shop.png)

Here is an example of a Shop menu with the **Grid** mode. You can use a similar approach on other menus. You will need a top-level Shop menu.

1. Go to **Appearance > Menus**
2. Choose **Primary Menu** and click **Select** button.
3. Go to **Shop** and choose **Mega Menu** 

![Mega Menu Horizontal Shop](_images/mega-menu--settings.png)

- In the **Mega Menu** tab, select **Enable Mega Menu**. <br/>
- In the **Mode** option, select **Grid**. <br/>
- Select **Width** as choose **Full Width**.

![Mega Menu Horizontal Shop - Menu Tab](_images/mega-menu__horizontal-shop--menu-tab.png)

4. Click **Save Changes** button.

- Click on **Add Column** to display 5 columns. <br/>
- Click on the **"+"** to add a menu item. <br/>
- In the **Mega Menu item** tab, select **Heading** to add a heading for the column. <br/>
- Click **Add to Menu**.

![Mega Menu Horizontal Shop - Settings](_images/mega-menu__horizontal-shop--settings.png)

- In the Heading settings, you enter the **Navigation Label and Url**. <br/>
- Select the option and choose **Label** to display the heading format.

![Mega Menu Horizontal Shop - Heading Settings](_images/mega-menu__item--heading.png)

Then, you can add other menu items to the **Add Menu Item** column after the heading to display content for each column.

![Mega Menu Horizontal Shop - Settings Success](_images/mega-menu__horizontal-shop--settings-success.png)

Click **Save Changes** button.
