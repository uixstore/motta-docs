# Logo
![Header logo](_images/header--logo.png)
![Header logo Customize](_images/customize--header-logo.png#alignright)
You can change the logo image, select to use text logo, adjust margin,... in **Appearance > Customize > Header > Logo**. 
- **Logo Type** - To select logo type either Image, Text or SVG code.
- **Logo** - To upload your main logo image, text, or SVG code.
- **Logo Dimension** - this option is used to adjust the logo image/svg dimension.

### Change logo image

To change the logo image, you must ensure the option **Logo Type** must be **Image**. Then select the logo image with options **Logo**.


### Text Logo

If you want to use text logo, Motta has options helping you design your text logo easily. Please follow these steps:

1. Select **Logo Type** as **Text**.
1. Enter the text for your logo in option **Logo Text**.
1. Select the favourite font variations for your logo. You can select font family, font weight, font size, letter spacing, text transform in **Appearance > Customize > Typography > Header Logo Text**


### SVG Logo

Motta allows you use SVG image for your logo. There are 2 methods to use SVG logo.

1. Select **Logo Type** option as **SVG** then paste the SVG code to the textarea option bellow.
2. Replace the default Motta logo by your own. You just need to install the motta child theme and upload your svg logo image to the `_images` folder. You logo image must be named as `logo.svg`.


### Retina logo

If you are using text logo or SVG logo, it is retina ready by default.

But if you are using image logo, there are 2 options that allow you to specify the width and height of your logo image. They are **Logo Width** & **Logo Height**. By default, you don't need to enter values for them. The logo will be display in nature dimension. But if you want the logo displays well on retina screens, you should prepare it in double dimension then enter these values as regular dimension. For example, your logo is 140x70, you should design it in 280x140. Then enter the value of width is 140px or height is 70px.

> [!TIP] You should set one value only (Width or Height). If you set both values, it make display your logo incorrectly on mobile.
