### Sticky Header

A sticky header is a header that remains visible at the top of the viewport even when the user scrolls down the page

Motta supports 2 kinds of sticky header and also allows to disable it. By default, it is disabled. You can select either disable, normal sticky or custom sticky.


## Normal Sticky Header

![](_images\sticky-header-options.png#alignright)

Just go to **Appearance > Customize > Header > Header Sticky** select the options below:

- **Sticky Header** - Select the Normal Sticky
- **Sticky Header Section** - Select the header section that you want to make sticky. You can select either the **Header Main** or the **Header Bottom** section.
- **Height** - To set the height of the sticky 

## Build your own Sticky Header

![](_images\custom-sticky-header-options.png#alignright)

If you don't like one of pre-build the sticky header, or sometimes you want to build your own sticky header, or just simply add/remove icons on the sticky header.

Just go to **Appearance > Customize > Header > Header Sticky** select the options below:

- **Sticky Header** - Select the Custom Sticky
- **Height** - To set the height of the sticky header
- **Left Items** - add/remove items to/from the left section of the sticky header. You can also reorder them.
- **Center Items** - add/remove items to/from the center section of the sticky header. You can also reorder them.
- **Right Items** - add/remove items to/from the right section of the sticky header. You can also reorder them.
