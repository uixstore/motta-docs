# Config Mega Menu

The theme adds some options to the menu item. They allow you to config mega menu. Click the **Mega Menu** link in every menu item to show options.

## Mega Menu Settings

When you select the menu at the highest level (level 1), the mega menu settings will appear. You will see new settings for each menu item. Each level of the menu will be displayed differently.


![Settings Menu](_images/mega-menu--settings.png)

## Mega Menu Content


### Mega Menu Tab

![Mega Menu Tab](_images/mega-menu--menu-tab.png)

1. **Enable Mega Menu** - Enable/disable mega menu.
2. **Mode** 			- Default, Grid and Tabs.
3. **With**				- Default, Full Width, Custom (px).

#### Mega Menu Mode Grid

![Mega Menu Mode Grid](_images/mega-menu--mode-grid1.png)

1. Drag and drop the position between rows
2. Add Column
3. Remove row and Row options
4. Adjust or drag and drop the width of column
5. Remove column, Reset width and Column options
6. Add menu items for each column
7. Add Row

> [!NOTE] When you select the option of a row or column, a popup option will appear that includes the padding and background of the row or column.

**Row option and Column option**

![Mega Menu Mode Grid Option](_images/mega-menu--mode-grid-option.png)

#### Mega Menu Mode Tab

![Mega Menu Mode Tab](_images/mega-menu--mode-tab.png)

1. You have 2 options to switch between tabs: Open on Hover and Open on Click.
2. When you click on the edit tab, it will go to the sub menu item and add item.


### Design Tab

![Mega Menu Design Tab](_images/mega-menu--design-tab.png)

1. **Background** - Add a background to the menu item.
2. **Menu Image** - Add a background to the menu item in the mobile menu.


## Menu Icon

You can choose in the mega menu settings or you can choose directly outside the menu item.

![Mega Menu Icon](_images/mega-menu--icon.png)

**Icon Settings**

![Mega Menu Icon Settings](_images/mega-menu--icon-setting.png)

1. **Type**
	- **No icon**
	- **Theme**: Select the icons from the theme.
	- **Image**: Upload the image icon.
	- **Svg Code**: Select a SVG code. 
2. **Background Color** - Add a background color to the icon.
3. **Color** - Add a color to the icon.
4. **Hide Text** - Hide a menu title.



## Menu Settings

Only second level items can have this tab.

![Mega Menu Settings](_images/mega-menu--menu-settings.png)

1. **Visibility** - This option allows you to set the visibility of mega menu column label. It is visibile by default.
2. **Disable link** - Remove link from the mega menu column label.



## Menu Content

From menu items level 2 and bellow, you can set a custom HTML content for them. For example, you can hide the column lable then display a HTML/Shortcode of a banner image on the menu.

![Mega Menu Content](_images/mega-menu--menu-content.png)

> [!TIP] To build complex mega menu content, you can build your content inside a page with visual page builder then copy generated content here.
