### Campaign Bar

![](_images/campain-bar.png)


![](_images\customize--campaign-bar.png#alignright)

You can go to **Appearance > Customize > Header > Campaign Bar** to control the Campaign Bar, such as turning it on/off, selecting the Campaign Bar position, and setting the content for it.

- **Campaign Bar** - To enable/disable the Campaign Bar.
- **Campaingn Items** - To add/remove campaign content.
- **Position** - To place the Campaign Bar before or after the header
- **Background Image** - To set the background image of the Campaign Bar.
- **Background Color** - To set the background color of the Campaign Bar.
- **Text Color** - To set the color of the text on the Campaign Bar. The default color is black.
- **Height** - To set the height of the Campaign Bar. The default height is 44 pixels.
- **Text Size** - To set the size of the text on the Campaign Bar. The default size is 14 pixels.
- **Text Weight** - To set the weight of the text on the Campaign Bar. The default weight is bold.
- **Bottom Spacing** - To set the bottom spacing of the Campaign Bar. The default spacing is 31 pixels.
