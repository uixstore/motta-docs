# Display Settings

![Page display settings](_images/page--settings.png#alignright)

Motta also supports customizing these things for each individual page.

When you edit a page with Elementor, and click the settings icon in the lower left corner of the Elementor Widget Panel, you will see options to control the following: Header, Footer, Page Header, Content Settings.

These options are located in a box in the Elementor Widget Panel.

In this box, you will see following sections.


## Site Header

![Page display settings](_images/page-settings_header.png#alignright)

In this section, you can change the style of the site header.

- **Hide Header Section** - Enable this option to hide the Header section of the current page
- **Header Layout** - Select a different header layout for the current page. It includes the following options:
	+ **Default Header Global** - the header layout that will be used on this page is the one that you have selected in the Header Global section of the Customizer > Header > Header Layout
	+ **Default Header Page** - the header layout that will be used on this page is the one that you have selected in the Header Page section of the Customizer > Page > Prebuilt Header
	+ **Header Vx** - Select a header version of the current page.
- **Hide Topbar** - Enable this option to hide the Topbar of the current page
- **Hide Campain Bar** - Enable this option to hide the Campain Bar of the current page
- **Hide Border Bottom** - Enable this option to hide the bottom border of the header of the current page.
- **Primary Menu** - Select a primary menu of the current page. By default, it will use the Default value which is set in the Theme Customizer
- **Category Menu Display** - Display the category menu when the user hovers over the category menu title/icon, or when the page loads.
- **Header Transparent** - Enable this option to show the Header Transparent of the page. This option only works with Header V12
- **Header Text Color** - Select a text dark/light for the header of this page. This option only works with the Header Transparent
- **Logo Type** - Select a logo type of the current page. By default, it will use the Default value which is set in the Theme Customizer
- **Logo Image** - Select a logo type as image of the current page. By default, it will use the Default value which is set in the Theme Customizer
- **Logo Text** - Select a logo type as text of the current page. By default, it will use the Default value which is set in the Theme 
- **Logo SVG** - Select a logo type as SVG of the current page. By default, it will use the Default value which is set in the Theme Customizer



## Page Header

![Page display settings](_images/page--settings_page-header.png#alignright)

This section contains options for controlling the page header of the current page only.

- **Hide Page Header** - Enable this option to hide the Page Header of the current page
- **Hide Tilte** - Enable this option to hide the Page Title of the current page
- **Hide Breadcrumb** - Enable this option to hide the Breadcrumb of the current page

## Content

![Page display settings](_images/page--settings_content.png#alignright)

This section contains options for controlling the layout of the current page.

- **Top Spacing** - custom the top spacing between the header and page content.
	- **Default** - It is 60px by default.
	- **No Spacing** - Remove the top spacing between the header and page content.
	- **Custom Spacing** - Custom the top spacing between the header and page content.
- **Bottom Spacing** - custom the top spacing between the footer and page content.
	- **Default** - It is 60px by default.
	- **No Spacing** - Remove the top spacing between the footer and page content.
	- **Custom Spacing** - Custom the top spacing between the footer and page content.

## Footer
![Page display settings](_images/page--settings_footer.png#alignright)

- **Hide Footer Section** - Enable this option to hide the Footer Section of the current page
- **Layout** - Select a footer layout for the current page on Desktop. The footer layout will be created by Elementor in Templates > Footer Builder.
- **Mobile Layout** - Select a footer layout for the current page on Mobile. The footer layout will be created by Elementor in Templates > Footer Builder.

## Navigation Bar
![Page display settings](_images/page--settings_navigation-bar.png#alignright)

- **Hide Navigation Bar** - Enable this option to hide the Navigation Bar of the current page
