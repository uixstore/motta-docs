# Control Shop Display

In order to manage the display of the product catalog pages (like shop, category, tag pages), Motta add options in **Appearance > Customize > Shop**. You will have options for shop page layout, product card, etc.

## Page Header

On the product catalog pages, this theme display a page header on top. You can disable it or change the style of this page header. At this moment, Motta supports 3 styles for this page header.

![Shop page header standard](_images/woocommerce--page-header-standard.png)
*Standard*

![Shop page header minimal](_images/woocommerce--page-header-minimal.png)
*Minimal*

![Shop page header breadcrumb](_images/woocommerce--page-header-breadcrumb.png)
*Breadcrumb*

You can change it in **Appearance > Customize > Shop > Page Header**. It is the option **Page Header Style**.

## Shop Header

On the product catalog pages, this theme display a shop header on top. You can disable it or change the content of the shop header. 

![Shop header](_images/woocommerce--shop-header.png)

You can change it in **Appearance > Customize > Shop > Shop Header**. 
 - **Shop Header**: To enable/disable the shop header
 - **Page Template**: To select a page template that created in **Dashboard > Templates > Section**. You can import this page template in [Elementor Templates]. It is called Shop Header

## Top Categories

On the product catalog pages, this theme display a top categories on top. You can disable it or change the style of this top categories. At this moment, Motta supports 2 styles for this top categories.

![Shop top categories v1](_images/woocommerce--top-categories-v1.png)
*Layout v1*

![Shop top categories v1](_images/woocommerce--top-categories-v2.png)
*Layout v2*

You can change it in **Appearance > Customize > Shop > Top Categories**.


## Catalog Toolbar

By default, you will see a products toolbar above products listing on the shop page, you can control this toolbar in **Appearance > Customize > Shop > Catalog Toolbar**.

At this moment, Motta supports 2 products toolbar layouts. In this sections, you can control the columns switcher, products tabs or the way to open products filter.

![Products Toolbar layout v1](_images/woocommerce--products-toolbar-v1.png)
*Layout v1*

![Products Toolbar layout v2](_images/woocommerce--products-toolbar-v2.png)
*Layout v2*


## Catalog Sidebar

- To enable the catalog sidebar, you can go to **Appearance > Customize > Shop > Product Catalog**. In the Sidebar section, select the Left Sidebar or Right Sidebar option.

- To add the content to the catalog sidebar, you can go to **Appearance > Widgets > Catalog Sidebar**. In the Catalog Sidebar section, drag and drop the widgets you want to add.

## Change Products Columns & Rows

![WooCommerce settings for rows and columns](_images/woocommerce--settings-rows-columns.png#alignright)

By default, WooCommerce supports to change how many products per row or how many rows per page. You can change it in **Appearance > Customize > WooCommerce > Product Catalog**.

> [!NOTE] If you enable the Products Toolbar, you will see it contains options that let visitors change the product columns. After a visitor select a different columns layout, he/her selection will be stored. And on the next time he/she comeback to your website, the shop will use that stored selection to display your products.


## Change the Products Order

WooCommerce comes with a variety of sorting options. By default, the sort order for your products is “Custom Ordering + Name”. With this order option, you are able to sort product manually. Just navigate to **Products**, the click **Sorting**.

![Products custom sorting](_images/woocommerce--products-sorting.png)

From this page, you can simply drag and drop the product rows to reorder them. You could also filter by category and change the ordering per category.

It’s worth noting that this isn’t a very flexible sorting option, but it should mostly do what you need.

When you add new products they will show up first in the list.

If you wanted to change the default sort order, you can do that under **Appearance > Customize > WooCommerce > Product Catalog**. There is an option **Default product sorting** that allows you to change the default sort order.


## Change Product Card

Motta support 5 product cards for products on product listing pages.

- [Product Card v1](https://motta.uix.store/product-card)
- [Product Card v2](https://motta.uix.store/product-card/?product_card_layout=2)
- [Product Card v3](https://motta.uix.store/product-card/?product_card_layout=3)
- [Product Card v4](https://motta.uix.store/product-card/?product_card_layout=4)
- [Product Card v5](https://konte.uix.store/product-hover-style/?shop_product_hover=simple)

You can change it in **Appearance > Customize > Shop > Product Catalog > Product Card**. It is the option **Product Layout**.

## Change Product Card Hover

Motta support 4 product card hover for products on product listing pages.

- [Standard](https://motta.uix.store/product-hover-style/?product_card_hover=standard)
- [Slider](https://motta.uix.store/product-hover-style/?product_card_hover=slider)
- [Zoom](https://motta.uix.store/product-hover-style/?product_card_hover=zoom)
- [Fadein](https://motta.uix.store/product-hover-style/?product_card_hover=fadein)

You can change it in **Appearance > Customize > Shop > Product Catalog > Product Card**. It is the option **Product Hover**.
