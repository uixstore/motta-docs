# Filter by Color

![](_images/filter-by-color.png)

### Options

![](_images/filter-by-color-options.png#alignright)

 - **Filter By** - select Attributes
 - **Attribute** - select Color
 - **Display Type** - select Auto

### Setup Color Attribute

To setup color attribute, you need to follow the steps below:

1. Install and Activate **WCBoost – Variation Swatches** plugin
2. Go to **Products > Attributes** create a new atrribute and select Type is color

![](_images/create-color-atrribute.png)

3. Go to **Products > Attributes > Color** click Configure terms

![](_images/color-attribute-edit.png)

4. Hover an item and click edit

![](_images/edit-color-attribute.png)

5. Select a color you want

![](_images/select-color-attribute.png)
